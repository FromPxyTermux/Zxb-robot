# 第19届“振兴杯”服务机器人应用技术员赛项（学生组）理论题库 · 练习系统

把官方《理论试题库》与《参考答案》整合，并做成一个**离线可用、可导入题库**的刷题网页（对标“考试宝”的练习体验）。

- 题库：**1000 题**（单选题 600 + 判断题 400），答案与原参考答案逐题核对一致
- 练习方式：顺序 / 随机 / 背题模式 / 模拟考试（限时评分）/ 错题本 / 收藏 / 未做题
- 无需安装、无需联网：双击 `服务机器人练习题库.html` 就能用

## 快速开始

| 想干什么 | 打开什么 |
|---|---|
| 直接刷题 | `服务机器人练习题库.html`（双击，手机也能用） |
| 改代码 | `题库练习系统/index.html` |
| 导入到其它平台（考试宝等） | `题库导入表.xlsx` 或 `题库-可导入文本.txt` |
| 看带答案的 Word 版题库 | `第十九届“振兴杯”赛项理论题库-学生组（含参考答案）.docx` |

手机从电脑访问：在 `题库练习系统/` 里执行 `python -m http.server 8000`，手机同 Wi-Fi 打开 `http://电脑IP:8000`。

## 功能（对齐考试宝常用模式）

- **顺序练习**：按题号逐题练，答完即时判对错并显示正确答案
- **随机练习**：打乱顺序抽题
- **背题模式**：直接显示答案快速过题，「我记住了 / 没记住」记录掌握情况
- **模拟考试**：默认 100 题（单选 80 + 判断 20）、限时 100 分钟，可改；交卷给分 + 错题回顾 +「重做错题」
- **错题本**（答对可自动移出）、**我的收藏**、**未做题目**
- **答题卡**：题号网格看进度（绿=对、红=错、蓝=已选），点击跳题
- **统计**：覆盖率、累计正确率、分题型掌握情况、今日作答
- **设置**：选项乱序、答对自动下一题、夜间模式、字号、考试题量/时长
- **进度自动保存**（浏览器 localStorage）
- **键盘操作**：`A~D`/`1~4` 选项，`←/→` 切题，`Enter` 下一题
- **导入题库**：粘贴文本或选择 `.txt/.json/.csv`，自动识别单选/多选/判断

导入格式示例：

```
1. ROS（Robot Operating System）属于？
A.数据库 B.中间件/通信框架 C.操作系统内核 D.编程语言
答案：B

2. 锂电池严禁过充和过放（）
答案：√
```

## 重新生成（改了题库后用）

```powershell
cd 题库练习系统\开发工具
python _parse_bank.py     # docx → questions.json + 题库-可导入文本.txt
python _gen_bank_js.py    # questions.json → bank.js
python _build_single.py   # 打包 → 服务机器人练习题库.html
python _make_xlsx.py      # → 题库导入表.xlsx
node _test_core.js        # 逻辑层单测（46 项）
node _test_dom.js         # 页面端到端测试（79 项）
node _test_single.js      # 单文件版冒烟测试（14 项）
```

依赖：Python 3（`python-docx`、`openpyxl`）、Node.js（测试用 `jsdom`）。
