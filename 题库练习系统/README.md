# 题库练习系统（第19届“振兴杯”服务机器人应用技术员·学生组）

一个**离线可用、可导入题库**的刷题工具（对标“考试宝”的练习体验），内置本赛项 1000 题，
无需安装、无需联网、不需要服务器，双击 HTML 就能用。

---

## 一、三种打开方式

| 方式 | 操作 | 适用 |
|---|---|---|
| **单文件版（推荐）** | 双击上级目录的 `服务机器人练习题库.html` | 一个文件搞定，发给同学/拷到手机都能用 |
| 文件夹版 | 双击本目录 `index.html`（依赖同目录 core.js / bank.js / app.js） | 便于改代码 |
| 手机访问 | 在本目录运行 `python -m http.server 8000`，手机同 Wi-Fi 打开 `http://电脑IP:8000` | 想在手机上刷题 |

> 单文件版是把 index.html + core.js + bank.js + app.js 内联成的一个 HTML，与文件夹版功能完全一致。

## 二、功能（对齐考试宝常用模式）

- **顺序练习**：按题号从头练，答完即时判对错、显示正确答案
- **随机练习**：打乱题目顺序抽题练
- **背题模式**：直接显示答案快速过题，用「我记住了 / 没记住」记录掌握情况
- **模拟考试**：默认抽 100 题（单选 80 + 判断 20）、限时 100 分钟，可改；交卷后给分数 + 错题回顾，支持「重做错题」
- **错题本**：答错自动收录，在里面答对可自动移出（可开关）
- **我的收藏 / 未做题目**：重点题二刷、专挑没做过的题
- **答题卡**：题号网格一眼看进度（绿=对、红=错、蓝=已选），点击直接跳题
- **统计**：已练覆盖率、累计正确率、分题型掌握情况、今日作答
- **设置**：选项乱序（防止只背“答案在第几个”）、答对自动下一题、夜间模式、字号、考试题量/时长
- **进度保存**：作答记录/错题/收藏/设置自动存在浏览器 localStorage，关掉再打开继续
- **键盘操作**：`A~D`/`1~4` 选项，`←/→` 切题，`Enter` 下一题

## 三、导入别套题库

进入「导入题库」页，两种方式：

1. **粘贴文本**（推荐格式，每题一空行分隔也行）：

```
1. ROS（Robot Operating System）属于？
A.数据库 B.中间件/通信框架 C.操作系统内核 D.编程语言
答案：B

2. 锂电池严禁过充和过放（）
答案：√

3. 下列属于编程语言的有？
A.JS
B.Python
C.HTML
D.C++
答案：ABD
```

- 题号可省略（按出现顺序自动编号）；`答案：`/`正确答案：`/`【答案】` 都能识别
- 选项可一行全写，也可每行一个；答案写多个字母即自动识别为**多选题**
- 判断题答案支持 `√ × 对 错 正确 错误 T F`
- 也支持直接粘贴 JSON：`{"title":"...","items":[{"type":"single","q":"...","options":["A项","B项"],"answer":0}]}`

2. **选择文件**：`.txt` / `.json` / `.csv`，读取后自动解析预览，确认题数无误再点「确认导入」。

> 导入会替换当前题库并清空练习记录；想还原点「恢复内置题库」即可。
> 本目录上级还有 `题库-可导入文本.txt`（本赛项 1000 题的纯文本）与 `questions.json`，可直接拿来导入。

## 四、导出与数据

- 统计页可导出：题库(txt)、题库(json)、学习记录(json)
- 上级目录 `题库导入表.xlsx`：序号/题型/题干/选项A-D/答案 的通用表格 + 答案速查表，可拿去其它平台或打印


## 六、开发工具（改题库后可重建）

```powershell
cd 题库练习系统\开发工具
python _parse_bank.py     # docx → questions.json + 题库-可导入文本.txt
python _gen_bank_js.py    # questions.json → 题库练习系统/bank.js
python _build_single.py   # 打包 → 服务机器人练习题库.html
python _make_xlsx.py      # questions.json → 题库导入表.xlsx
node _test_core.js        # 逻辑层单测（46 项）
node _test_dom.js         # 页面交互端到端测试（79 项）
node _test_single.js      # 单文件版冒烟测试（14 项）
```

（`node` 首次使用需在 PATH 中，本机为 `D:\juice\tools\node`。）
